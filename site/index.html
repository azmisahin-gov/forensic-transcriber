What is it?

Forensic Transcriber is a Windows desktop application for the expert area 56.12 — Ses Kayıtlarının Metin Haline Dönüştürülmesi. It imports a recording, records its technical metadata and a SHA-256, transcribes it locally with whisper.cpp, and gives you a review workspace where every transcript line is tied to the exact moment in the audio.

This software is a technical transcription and review aid. It does not itself constitute a forensic opinion, legal assessment, speaker identification, or authenticity determination. It is not a 56.11 forensic audio/video analysis system.

Why local?

  • Confidentiality. Recordings never leave the machine. Nothing is uploaded.
  • No account. No login, no cloud, no API key, no telemetry.
  • Works offline. The offline model package lets you install, launch and transcribe with no internet.
  • Traceable. Import hash, metadata and an action history are recorded as software provenance features.

How it works

  1. 1 New case
  2. 2 Import recording (picker or drag-and-drop)
  3. 3 Read metadata & hash the original
  4. 4 Transcribe locally (GPU or CPU)
  5. 5 Click a line → play that exact audio region
  6. 6 Edit, split, merge, label speakers, verify
  7. 7 Export JSON / TXT / SRT / HTML

Quick start

  1. Download and run the installer.
  2. Open the application and go to Models → Install.
  3. New case, then import a recording.
  4. Press Transcribe.
  5. Review each line against the audio, edit, save, export.

You do not need Python, Node.js, Rust, CMake, the CUDA Toolkit or FFmpeg installed. Those are only needed to build the application from source.

Privacy

No telemetry. No analytics. No login. No account. No audio upload. Case data is stored in a local SQLite database on your machine. The only outbound network call in the whole application is the explicit, checksum-verified model download you trigger.

This site is static documentation and a download portal. Do not upload case material here. This website does not process audio. GitHub, which hosts this page, states that it records visitors' IP addresses for security purposes.

Limitations

  • Automatic output is a first draft and always requires expert review.
  • No speaker identification, diarization-based naming, emotion/lie detection or authenticity analysis — those are out of scope.
  • Video files are accepted only for their audio track.
  • PDF export is not included in this release.
  • Turkish accuracy drops on noisy, overlapping or telephone-quality audio.
